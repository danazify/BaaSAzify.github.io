# BaasLab

Projeto educacional/profissional para construção de uma plataforma BaaS simulada, com foco em arquitetura segura, ledger financeiro, contas de pagamento, Pix mockado, conciliação, webhooks, auditoria e boas práticas de produção.

## Objetivo

Construir uma plataforma BaaS em .NET, simulando componentes reais de uma operação financeira, incluindo:

- Tenant/parceiros
- Clientes finais
- Contas de pagamento
- Ledger
- Saldo
- Extrato
- Transações internas
- Pix mockado
- DICT mockado
- SPI mockado
- Webhooks
- Conciliação
- Segurança
- Auditoria
- Observabilidade

## Aviso importante

Este projeto é um laboratório técnico e não representa uma instituição financeira real, não acessa SPI/DICT reais e não executa liquidação financeira real.
